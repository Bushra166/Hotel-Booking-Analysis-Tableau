# 🏨 Hotel Booking Analysis Dashboard Using Tableau

## 📌 Project Overview

The Hotel Booking Analysis Dashboard is an interactive Business Intelligence project developed using Tableau Desktop. The project analyzes hotel booking data to identify booking trends, customer behavior, revenue performance, cancellation patterns, and operational insights.

The objective of this project is to transform raw hotel booking data into meaningful visual insights that help hotel management make data-driven decisions.

---

## 🎯 Project Objectives

- Analyze hotel booking trends.
- Monitor booking cancellations.
- Study customer booking behavior.
- Analyze Average Daily Rate (ADR).
- Identify the most effective booking channels.
- Compare City Hotel and Resort Hotel performance.
- Build interactive dashboards for business decision-making.

# 📈 Key Business Insights

- City Hotels received more bookings than Resort Hotels.
- Around 37% of bookings were cancelled.
- ADR varied across different months.
- Distribution channels significantly influenced booking volume.
- Customer booking behavior differed across market segments.
- Country-wise booking analysis helped identify major markets.
